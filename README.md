# AI Sales Copilot — MVP 0.1 Alpha

Локальный помощник менеджера на Windows: Python/FastAPI, SQLite, React/TypeScript/Vite. Интерфейс работает в браузере. Никаких подключений Sipuni, CRM, аудио или внешнего сервера. Проект «ВЛЮДИ» не используется.

## Быстрый запуск

На этом компьютере зависимости и сборка подготовлены в папке проекта. Дважды нажмите **Start.cmd**, затем откройте **http://127.0.0.1:8765**. Оставьте окно запуска открытым; Ctrl+C останавливает приложение.

На новом Windows-компьютере:

1. Установите Python **3.12** с python.org и Node.js **22.12+** с nodejs.org.
2. Распакуйте проект в отдельную папку. Дважды нажмите **Install.cmd**. Интернет нужен для загрузки зависимостей.
3. Нажмите **Start.cmd**, откройте адрес выше. Docker не нужен.

Если Windows блокирует скрипт, откройте PowerShell в папке проекта и выполните `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1`. Это разрешение действует только для данного запуска.

## Первая проверка

### Компактный интерфейс

Список разговоров открывается кнопкой ☰. «Рабочий экран» показывает диалог и подсказку рядом; ввод закреплён снизу, Ctrl+Enter отправляет реплику. Карточка клиента показывает заполненные поля; неизвестные сведения находятся во вкладке «Уточнить», прежние советы — в «Истории». «Все поля и изменения» раскрывает полную память. Объяснение совета раскрывается отдельно.

Для работы рядом с другим приложением выберите «Только подсказка» и сузьте окно браузера. Это компактный браузерный режим, не окно поверх других приложений. «Подробный разбор» показывает объяснение постоянно. После обновления версии нажмите Ctrl+F5 в браузере.

Создайте разговор → раскройте «Тестовые сценарии» → выберите Excel → последовательно нажмите «Следующая тестовая реплика» 18 раз. Следите за карточкой клиента, источниками и подсказками. Завершите разговор и скачайте итог JSON. Перезапуск сохраняет сессии. Для нового сценария создавайте новую сессию. Позиция симулятора сбрасывается при переключении разговора.

## Режимы анализа и ключи

Для пошагового подключения запустите **Connect-model.cmd**. Мастер предлагает DeepSeek Flash или другой совместимый HTTPS API, скрыто принимает ключ и отправляет одну синтетическую реплику для проверки. Только после успешной проверки он сохраняет настройки в `.env`. Ключ в чат не отправляйте. Сначала зарегистрируйтесь у выбранного провайдера и проверьте доступность оплаты для своего аккаунта.

После подключения остановите приложение Ctrl+C, снова откройте Start.cmd и создайте новый разговор. Для DeepSeek отключено дополнительное рассуждение ради первого теста задержки; ответ ограничен 3000 токенами. Скорость и качество ещё необходимо измерить на реальной модели.

По умолчанию `LLM_PROVIDER=demo`: полностью автономные **упрощённые правила**, не полноценный ИИ. Демо проверяет ввод, сохранение, ссылки на источники, смену сроков и цикл рекомендаций. Оно не понимает произвольные отрицания, сложные причины и контекст так, как языковая модель. Не используйте его для оценки качества интеллекта.

Для модели скопируйте `env.example` в `.env` и заполните:

```dotenv
LLM_PROVIDER=compatible
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_MODEL=имя-установленной-модели
LLM_API_KEY=
LLM_TIMEOUT=45
DATABASE_PATH=data/copilot.sqlite3
```

Адаптер использует совместимый `/chat/completions` API с `response_format: json_object`. Адрес примера рассчитан на отдельно запущенный локальный сервис модели; сам проект модель не устанавливает. Для облачного провайдера укажите его HTTPS endpoint, имя модели и ключ. Провайдер должен поддерживать JSON-режим. Полный диалог, память и синтетическая база продуктов передаются указанному сервису. Перезапустите приложение после изменений `.env`.

Ключ читается только backend, никогда не передаётся браузеру. `.env`, база, зависимости и журналы исключены из Git. Не добавляйте ключи в `env.example`, сценарии или исходники. Внешняя модель без настроенного провайдера/ключа не проверялась. Проверка JSON и цитат не гарантирует истинность смысловых выводов модели.

## Что реализовано

- Сессии, последовательные реплики менеджера/клиента, сохранение и удаление.
- Защита от повторной отправки по request_id и конфликтов версий.
- 13 категорий памяти, цитаты, ссылки на реплики, предположения, история замены фактов.
- Одна подсказка, объяснение, источники, оценки и история. Скрытые/отклонённые точные повторы подавляются.
- Обработка отказов, уточнение неоднозначных возражений в демонстрационных сценариях.
- Подключаемый LLM, проверка структуры и ссылок, версия промпта, длительность ответа и usage при обычном анализе.
- Сохранение реплики при ошибке модели и повтор анализа без повторного ввода.
- Сводка подтверждённых фактов, неизвестные поля остаются неизвестными.
- Синтетическая база Excel Базовый / PRO / Мастер без выдуманных цен.
- 5 сценариев, включая полный разговор из 18 реплик, и автоматические тесты.

## Границы Alpha и дальнейшая работа

Это запускаемая Alpha, а не полная приёмка ТЗ 0.1. В исходной беседе найден текст ТЗ; Word был указан ссылкой sandbox, но недоступен среди вложений. Не реализованы экспертный разбор менеджера, импорт произвольных файлов диалога, сравнение моделей, 50 размеченных сценариев и закрытый контрольный набор. Метрики precision/recall/уместности и p95 ещё не измерены. Презентация под потребность работает через LLM-промпт и требует экспертной проверки. Демо специально не имитирует такую проверку.

Память ограничена одной сессией: автоматического объединения разных разговоров одного клиента пока нет. Сводка выводится как структурированный JSON. Нет авторизации и шифрования базы: приложение только для одного локального пользователя, синтетических данных и запуска на 127.0.0.1. Не открывайте порт в сеть. Ограничение — 200 реплик в сессии; при длинных разговорах возможен предел контекста провайдера. Запуск только одним процессом, без `--workers`: очередь изменений общая для локального приложения.

## Разработка и тесты

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8765
# Во втором окне, только для разработки:
cd frontend
npm run dev
# Проверка frontend:
npm run build
```

Документация API: http://127.0.0.1:8765/docs. Все маршруты имеют префикс `/api`: sessions, turns, retry, close, summary, feedback, scenarios, config, health. Frontend в рабочем режиме отдаётся самим FastAPI после сборки; второй процесс Node не нужен.

Структура: `backend/models.py` — контракты; `context.py` — память и валидация; `providers.py` — demo/LLM; `prompts.py` — инструкции модели; `storage.py` — SQLite; `main.py` — API; `frontend/src` — интерфейс; `evaluation` — тестовые диалоги.

Данные: `data/copilot.sqlite3`. Для резервной копии остановите приложение и скопируйте этот файл. Удаление сессии удаляет её диалог, память и оценки из рабочей базы; ранее сделанные копии остаются у вас.

Технические справочники: [FastAPI](https://fastapi.tiangolo.com/tutorial/first-steps/), [Vite](https://vite.dev/guide/).
