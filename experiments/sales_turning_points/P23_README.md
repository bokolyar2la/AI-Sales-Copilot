# P2.3 — исторический пилот A/B

Запускать из корня проекта. Исходные файлы и все результаты находятся в игнорируемом `work/p23-private/`.
CSV импортируется без изменения оценок; его оценки относятся к историческим менеджерам, НЕ к ответам модели.
`evaluation_only.json` хранит разметку и реальные продолжения отдельно от `model_cases.json`.
При каждом запуске проверяются 20 ID, структура исходного корпуса и точность префикса.
В запросах нет экспертных ответов, допустимых действий из разметки или будущих реплик.
Исторические коммерческие утверждения остаются в истории как слова менеджера, но approved_claims пуст.
Текущего каталога нет — оценка должна учитывать невозможность подтвердить условия продукта.

Пилот: tp_1_7 (поправка мотива), tp_3_23 (стаж и работа), tp_4_2 (не готова говорить),
tp_5_23 (не понимает, зачем продукт нужен), tp_6_147 (условная готовность начать).
Это целевой, не статистически репрезентативный набор. Точка tp_5_23 содержит смешанную ASR-разметку
в последующем ответе менеджера; будущий ответ не входит в запрос. Корпус в целом требует выборочной сверки ASR.
C не реализован и не запускается.

## Только подготовка без сети

```powershell
.venv\Scripts\python.exe -m experiments.sales_turning_points.p23 --out work/p23-private/preview-new
```

## После отдельного разрешения на платную передачу обезличенных реальных диалогов

```powershell
.venv\Scripts\python.exe -m experiments.sales_turning_points.p23 --out work/p23-private/live-01 --allow-paid --allow-private-transcripts --max-calls 15
```

Новая папка должна быть пустой/не существовать. 5×(A до 2 вызовов + B 1 вызов) = максимум 15,
без recovery 10. Thinking disabled, temperature 0.2, максимум 3000 выходных токенов на вызов.
45 000 — верхняя граница только выходных токенов, НЕ общих токенов и НЕ лимит долларов.
Используется текущая локальная настройка DeepSeek из .env. Ключ не экспортируется.
A использует текущие production-промпт/валидатор/recovery; B исходный minimal_prompt, schema_only.
Общий контекст и факты одинаковы, инструкции и схемы намеренно различаются.

Журнал атомарно резервирует вызов до обращения и сохраняет ответ/контрольную точку.
Одинаковые сценарии, код, конфигурация и общий лимит проверяются при --resume.
Неопределённый оплаченный вызов НЕ повторяется автоматически; завершённые случаи пропускаются.
Для возобновления добавить --resume к той же команде; при неопределённом запросе сначала разбирать журнал.
Нельзя обходить неопределённость запуском новой папки без отдельного решения о возможной повторной оплате.

## Слепая оценка

После запуска передать эксперту ТОЛЬКО `live-01/reviewer/anonymous_answers.md` и
`live-01/reviewer/assessment_template.csv`. X/Y случайно переставляются для каждой точки.
Сейчас preview содержит пустые ответы, не вымышленные рекомендации.
Не передавать sealed_mapping.json, results.json, blind_review.csv старого стенда или технические логи:
они раскрывают вариант или профиль проверки. Слепота организационная, не шифрование файлов владельца.

Поля оценки: facts, motive_or_barrier, timing, repetition, product_accuracy, client_boundaries,
commercial_appropriateness, rationale, strong_decisions, error_pattern, critical_violations.
Это свободная экспертная оценка, не сравнение названий стратегий. Для отсутствующего ответа отметить
«нет ответа» и причину; не ставить ноль коммерческому качеству вместо технического пропуска.
После фиксации решения и обоснования для всех X/Y:

```powershell
.venv\Scripts\python.exe -m experiments.sales_turning_points.p23 --out work/p23-private/live-01 --review work/p23-private/live-01/reviewer/assessment_filled.csv
```

Сохраняются fixed_expert_review.json с хешем оценки и comparison.md: раскрытые варианты,
экспертные расхождения/сильные решения/метки повторных ошибок, исходная разметка для сопоставления,
измеренные задержки, токены, ошибки, блокировки и recovery. Автоматического победителя нет.
Заполненный CSV сохранять отдельным файлом; шаблон не содержит автоматических оценок.

## Финальная защита P23

Эксперимент имеет постоянный ID `p23-real-sales-pilot-v1`. До первого API-вызова он регистрируется
в `work/p23-private/paid_experiment_registry.json`. Общая блокировка запрещает параллельные запуски.
Новая папка не обходит регистрацию. Для намеренного повторения после отдельного согласования
нужно дополнительно передать `--authorize-repeat p23-real-sales-pilot-v1` и использовать новую папку.
При сбое резервация остаётся: автоматически сбрасывать реестр или удалять блокировку нельзя.
Для безопасного продолжения прежнего запуска используется --resume, с прежним лимитом 15.

В экспорт tp_6_147 применено локальное обобщение банков в c6t91–c6t97; c6t98–c6t99 сохранены.
Исходный корпус не перезаписан. Обе конфигурации получают одинаковое предупреждение о неподтверждённых
исторических условиях в системном сообщении, включая повторную генерацию A.
Независимый аудит отмечает возвраты, пробный период, скидки, рассрочку, гарантии и свойства курса.
Это чувствительный сигнал для эксперта, не семантическая гарантия отсутствия ошибок: вопросы/отрицания
тоже могут требовать проверки. Он не подменяет сырой ответ и не назначает победителя.
