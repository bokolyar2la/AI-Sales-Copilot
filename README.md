# AI Sales Copilot — первая итерация интеллекта v2

Локальный помощник менеджера EdTech. После новой реплики обновляет факты и проверяемые гипотезы, выбирает стратегию и показывает готовую фразу в карточке **«СКАЖИ КЛИЕНТУ»**. Python / FastAPI / SQLite / React / TypeScript / DeepSeek. Один пользователь, Windows, текстовый ввод.

## Запуск обновлённой версии на этом компьютере

1. Остановите старое окно запуска сочетанием **Ctrl+C**.
2. Откройте **Start.cmd** в папке проекта. Настроенный `.env` и сохранённые разговоры остаются на месте.
3. Откройте **http://127.0.0.1:8765** и обновите страницу **Ctrl+F5**.
4. Создайте **новый разговор** для чистой проверки новой логики. Вводите по очереди реально произнесённые реплики менеджера и клиента; отправка — **Ctrl+Enter**.
5. В карточке видны готовая фраза, стратегия, её цель и объяснение. Во вкладке «Клиент» раскройте гипотезы: они отделены от подтверждённых фактов и имеют ссылки на источники.

Кнопка вставки подсказки переносит её в черновик менеджера, но не отправляет. Показанная подсказка не считается произнесённой. Старые сессии открываются без миграции; старые советы не пересчитываются автоматически.

## Установка из репозитория на Windows

Установите Python 3.12 и Node.js 22.12+; загрузите проект в отдельную папку. Запустите **Install.cmd** — он установит зависимости и соберёт интерфейс. Затем **Connect-model.cmd** для подключения API и **Start.cmd** для запуска. Интернет нужен при установке и при обращении к облачной модели.

`Connect-model.cmd` скрыто принимает ключ, проверяет подключение синтетической репликой и сохраняет успешные настройки только в `.env`. Если `.env` уже настроен, повторно подключать модель не нужно. Не присылайте ключ в чат и не добавляйте его в Git.

По умолчанию `env.example` включает `demo`: это ограниченные автономные правила для проверки приложения, не полноценный интеллект. Для существующего DeepSeek используется `LLM_PROVIDER=compatible`, `LLM_BASE_URL=https://api.deepseek.com`, имя подключённой модели и локальный API-ключ. Используйте мастер настройки либо редактируйте локальный `.env`. `LLM_TIMEOUT` — таймаут одного запроса; при исправлении ответа возможен второй запрос.

## Полный цикл этой итерации

1. Реплика сохраняется в SQLite до обращения к модели.
2. `providers.py` передаёт историю, актуальную память и схему ответа в DeepSeek.
3. Модель возвращает изменения фактов, гипотез, событий разговора, стратегию и готовую фразу одним структурированным ответом.
4. `context.py` и `intelligence.py` проверяют источники и применяют изменения атомарно: невалидный ответ не повреждает память.
5. `dialogue_policy.py` контролирует уже заданные вопросы, запрос цены, готовность купить и отказ; валидатор проверяет форму фразы, повторы, источники продуктовых утверждений и соответствие стратегии.
6. `engine.py` допускает одну исправляющую попытку при ошибке схемы, источников или фразы. После второй неудачи показывается безопасное состояние/ошибка с возможностью повтора. История содержит проверки, число запросов, задержку и расход токенов успешного цикла.

Гипотезы не становятся фактами автоматически: подтверждение требует отдельного факта из реплики клиента; опровержение сохраняется с историей. Связь цитаты с выводом всё ещё требует смысловой оценки — программная проверка не заменяет эксперта.

## Проверки и реальные ответы

См. [отчёт итерации](ITERATION_1_REPORT.md) — 12 сложных синтетических ситуаций, дословные фразы DeepSeek, объяснения, замеченные ошибки и ограничения. Полный финальный прогон: `evaluation/iteration1-r3.json`. Проверка реального цикла API и сохранения: `evaluation/iteration1-api-smoke.json`.

Локальные тесты без платных API-запросов:

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
cd frontend
npm run build
```

Платный синтетический прогон из корня проекта, только по явному запуску:

```powershell
.\.venv\Scripts\python.exe -m evaluation.run_iteration1 --live
```

Можно ограничить сценарий: `--case goal_change`. Сценарии проигрываются по порядку, будущие ответы модели не передаются. Результаты сохраняются локально. Автоматические метрики не означают доказанную уместность или рост конверсии.

## Ограничения

- Нет аудио, Sipuni, CRM, сервера, кабинета школы и командной аналитики. Проект «ВЛЮДИ» не используется.
- База актуальных условий Skillbox не загружена. Нельзя достоверно презентовать конкретную программу, назвать цену или обещать поддержку без утверждённых данных. Историческая учебная база не считается офертой; продуктовые утверждения принимаются из явных `approved_claims`.
- Проверка смысловых повторов и качества гипотез частично зависит от модели. Одна пунктуационная вопросительная фраза иногда может содержать несколько смысловых запросов.
- До 200 реплик на сессию, полный контекст отправляется провайдеру; длинные разговоры стоят дороже и могут быть медленнее. Автоматическая коррекция увеличивает задержку и расход.
- Память пока в пределах одной сессии. Итог — структурированные факты, не полноценная оценка менеджера.
- Приложение запускается только на `127.0.0.1`, одним процессом, без `--workers`. Нет многопользовательской авторизации. Для реальных корпоративных данных нужны отдельные разрешения на обработку и передачу провайдеру.

## Файлы и данные

`backend/models.py` — контракты; `engine.py` — цикл; `context.py` — факты; `intelligence.py` — гипотезы/стратегия/валидатор; `dialogue_policy.py` — ход беседы; `intelligence_prompt.md` — инструкции v2; `frontend/src/main.tsx` — интерфейс; `evaluation` — синтетические проверки.

Локальные данные: `data/copilot.sqlite3` (или путь из `.env`). Для резервной копии остановите приложение и скопируйте базу. `.env`, базы, зависимости и журналы исключены из Git. API-документация после запуска: **http://127.0.0.1:8765/docs**.
